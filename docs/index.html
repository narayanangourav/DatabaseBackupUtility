Database Backup Utility

A cross-platform CLI and web UI for compressed database backups and restores.

Run the Container

docker run --rm -p 7575:7575 -v dbbackup-data:/data/backups ghcr.io/OWNER/dbbackup:latest

Open http://localhost:7575/backup after the container starts.

See the repository README for database connection, storage, restore, and security guidance.
